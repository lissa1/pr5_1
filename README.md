# Function Grapher

Интерактивное приложение на C++ для визуализации графика математической функции с поддержкой масштабирования и навигации.

## Функция

$$y = \frac{x^2 - 3}{(x-1)(5-x)}$$

### Характеристики функции:
- **Область определения**: ℝ \ {1, 5}
- **Вертикальные асимптоты**: x = 1 и x = 5 (показаны красными линиями)
- **Нули функции**: x = ±√3 ≈ ±1.732

## Возможности приложения

### 📊 Визуализация
- ✅ Построение непрерывного графика функции (синего цвета)
- ✅ Вертикальные асимптоты в точках разрыва (красные пунктирные линии)
- ✅ Координатная плоскость с осями X и Y (черные линии)
- ✅ Адаптивная сетка с автоматическим выбором шага
- ✅ Засечки и деления на осях в зависимости от масштаба
- ✅ Точка начала координат (0, 0) отмечена точкой
- ✅ Стрелки на осях, указывающие положительные направления
- ✅ Информационная панель с параметрами функции
- ✅ Размер единичного отрезка и координаты отображаются динамически

### 🎮 Управление

**Масштабирование (приближение/удаление):**
- `+` (или `=`) — приближение графика (zoom in)
- `-` — удаление графика (zoom out)

**Навигация по координатной плоскости:**
- `↑` — движение вверх
- `↓` — движение вниз
- `←` — движение влево
- `→` — движение вправо

**Альтернативное управление (WASD):**
- `W` — движение вверх
- `S` — движение вниз
- `A` — движение влево
- `D` — движение вправо

**Выход:**
- `ESC` — закрытие приложения

## Технические детали

### Особенности реализации

1. **Функция вычисляется точно** на каждой позиции пикселя для плавности кривой
2. **Обработка разрывов**: функция не рисуется вблизи точек x=1 и x=5
3. **Защита от больших значений**: точки с |y| > 500 игнорируются для стабильности
4. **Динамическая сетка**: 
   - При zoom out сетка становится крупнее
   - При zoom in сетка становится мельче
5. **Преобразования координат**: двусторонние функции для преобразования мировых координат в экранные

### Класс Graph

Основной класс, содержащий:
- **Приватные члены**: окно SFML, смещения, масштаб
- **Константы**: размеры окна, пределы масштаба, цвета
- **Публичные методы**: `run()`, `handleInput()`, `render()`, `update()`
- **Приватные методы**: 
  - `evaluateFunction()` — вычисление y = f(x)
  - `drawCoordinateSystem()` — рисование осей и сетки
  - `drawGraph()` — рисование самого графика
  - `drawAsymptotes()` — рисование асимптот
  - `worldToScreen()` / `screenToWorld()` — преобразования координат

## Требования

### Системные требования
- **ОС**: Linux, macOS, Windows
- **Компилятор**: C++17 или выше (GCC 7+, Clang 5+, MSVC 2017+)
- **CMake**: версия 3.10 и выше

### Зависимости
- **SFML (Simple and Fast Multimedia Library)** версия 2.5+
  - graphics module
  - window module
  - system module

## Установка и компиляция

### Linux/macOS

**1. Установка SFML:**
```bash
# Ubuntu/Debian
sudo apt-get install libsfml-dev

# macOS (Homebrew)
brew install sfml

# CentOS/RHEL
sudo yum install SFML-devel
```

**2. Компиляция проекта:**
```bash
mkdir build
cd build
cmake ..
make
```

**3. Запуск:**
```bash
./function_grapher
```

### Windows (Visual Studio)

**1. Установка SFML:**
- Скачать с https://www.sfml-dev.org/download/sfml/2.6.1/
- Распаковать в удобное место (например, C:\SFML)

**2. Компиляция:**
```bash
mkdir build
cd build
cmake .. -G "Visual Studio 16 2019" -DSFML_DIR="C:\SFML\lib\cmake\SFML"
cmake --build . --config Release
```

**3. Запуск:**
```bash
Release\function_grapher.exe
```

### Windows (MinGW)

```bash
mkdir build
cd build
cmake .. -G "MinGW Makefiles"
make
./function_grapher.exe
```

## Примеры использования

### 1. Просмотр общей формы графика
Запустите приложение в режиме по умолчанию. Видны две ветви гиперболы с асимптотами.

### 2. Исследование поведения вблизи асимптот
- Нажимайте `+` для приближения
- Используйте `→` для движения к точке x = 1

### 3. Навигация по графику
- Используйте стрелки для перемещения
- Экспериментируйте с масштабированием
- Найдите нули функции в точках x = ±√3

### 4. Анализ масштаба
Сетка и деления автоматически адаптируются к текущему масштабу для оптимальной читаемости.
